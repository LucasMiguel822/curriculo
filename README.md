# 📄 Currículo Online

## 📌 Sobre o Projeto

Este projeto consiste em um currículo online desenvolvido para apresentar minhas informações pessoais, formação acadêmica, objetivo profissional e habilidades. O objetivo é organizar essas informações em uma página web, facilitando a visualização do currículo.

## 🚀 Tecnologias Utilizadas

- **HTML5:** estruturação e organização das informações.
- **CSS3:** estilização e aparência visual da página.
- **Git e GitHub:** armazenamento e versionamento do projeto.

## ✨ Funcionalidades

- Apresentação das informações pessoais.
- Exibição do objetivo profissional.
- Apresentação da formação acadêmica.
- Listagem de habilidades e conhecimentos.
- Exibição do currículo diretamente pelo navegador.

## 📂 Estrutura do Projeto

```text
curriculo/
├── css/             # Arquivos de estilização
├── img/             # Imagens utilizadas no projeto
├── index.html       # Página principal do currículo
└── README.md        # Documentação do projeto
```

## ▶️ Como Executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/LucasMiguel822/curriculo.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd curriculo
   ```

3. Abra o arquivo `index.html` em um navegador para visualizar o currículo.
